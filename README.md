# Tape Calculator

A retro-inspired calculator web application built using **HTML, CSS, and JavaScript**. It combines a vintage calculator design with interactive functionality and a paper tape feature that keeps track of completed calculations.

## Features

* **Basic Arithmetic:** Perform addition, subtraction, multiplication, and division.
* **Percentage:** Calculate percentages.
* **Sign Toggle:** Switch between positive and negative numbers.
* **Backspace:** Delete the last entered digit.
* **Clear:** Reset the current calculation.
* **Calculation History:** Display completed calculations on an interactive paper tape.
* **Reuse Previous Results:** Click any previous calculation result to use it again.
* **Keyboard Support:** Perform calculations using your physical keyboard.
* **Error Handling:** Handle division by zero.
* **Responsive Design:** Adapt the layout to different screen sizes.
* **Interactive UI:** Animated calculator buttons and a retro-inspired visual design.

## Technologies Used

* **HTML5:** Structures the calculator interface.
* **CSS3:** Provides styling, animations, responsive layout, and visual effects.
* **JavaScript (ES6+):** Implements calculator logic, event handling, and interactive features.
* **Google Fonts:** Uses Chivo Mono and Bricolage Grotesque typography.

## Getting Started

### Prerequisites

* A modern web browser.
* Visual Studio Code (recommended).

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project directory:

```bash
cd Tape-Calculator
```

3. Open the project in Visual Studio Code.

4. Open `index.html` in your browser or use the Live Server extension.
